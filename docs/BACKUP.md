# バックアップ・復元・CSV

## 暗号化バックアップ

1. 設定 →「暗号化バックアップ・復元」を開きます。
2. 12文字以上のパスワードを入力します。他の場所に控え、端末とは別に保管してください。
3. 原本画像を含めるか選び、「バックアップを作成」を押します。
4. `.backup` ファイルがダウンロードされたことを「ファイル」アプリ等で確認します。ブラウザによっては保存/共有画面から保存先を選びます。
5. 作成したバックアップを開いて復号できることを確認できます。この時点では既存データを変更しません。確認後に「キャンセル」を選べます。

AES-256-GCM、ランダム16バイトsalt、12バイトIV、PBKDF2-HMAC-SHA256 310,000回、バージョンを識別する追加認証データを使用しています。パスワードは保存しません。紛失時の復旧機能はありません。これはバックアップファイルの暗号化であり、IndexedDB内の暗号化ではありません。

画像合計60MBまで。JSON/base64変換時は一時メモリが必要です。大量画像や低メモリ端末では「原本画像を含める」をオフにしてください。画像を別途保存する場合は写真ライブラリ等で管理してください。本アプリは画像を自動アップロードしません。初期版には分割/ストリーミングバックアップはありません。

## 復元

1. 現在のデータが必要なら、先にバックアップします。
2. 作成時のパスワードを入力し「バックアップを開く」でファイルを選択します。
3. 復号・形式検証後に表示されるレシート件数とカード設定件数を確認します。
4. 「全データを置き換えて復元」を押します。**追加ではなく置き換えです。**
5. 一覧・金額・カード設定・画像を確認します。

復号失敗、書式不正、重複ID、画像の型/サイズ不正では復元しません。書き込みはレシートと設定を含む1つのIndexedDBトランザクションで行い、途中で失敗した場合は以前のデータを保ちます。新しいバージョンでデータ形式を変更する際は、移行機能を実装してから更新します。

## Googleスプレッドシート

「レシート一覧CSV」と「商品明細CSV」を出力します。両方にレシートIDを含みます。

1. Googleスプレッドシートで新規ファイルを開きます。
2. ファイル → インポート → アップロードからCSVを選びます。
3. 各CSVを別シートに読み込みます。文字コードはUTF-8、区切りはカンマです。
4. IDや下4桁を保つには「テキストを数値、日付、数式に変換する」をオフにします。金額列は必要に応じて数値へ変換します。カード下4桁は `末尾 0042` の形式です。
5. 合計は支払者と通貨で分けます。SGDとJPYをそのまま足さないでください。

CSVはBOM付きUTF-8、CRLF、全セルを引用符で囲み、内部の引用符は二重化します。数式の開始文字（空白/制御文字の後の `= + - @` など）には先頭アポストロフィを付けます。負の金額も安全のためテキスト化される場合があります。エクスポート後に防御文字を除去した自由記入セルを数式として再解釈しないでください。

CSVは**平文**で、暗号化バックアップではありません。Googleへのアップロードはユーザーが明示的にインポートしたときに行われます。本アプリ自体はGoogleに接続しません。
