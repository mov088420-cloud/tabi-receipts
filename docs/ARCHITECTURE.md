# 構成

```text
画像(File) → Canvasで回転・縮小・明暗調整
          → 1つのTesseract Worker (英語/LSTM)
          → OCR全文（メモリのみ）
          → ルールベース解析 → 確認・修正画面
          → スキーマ検証 → IndexedDB
                                 ├─ 一覧・検索・通貨別集計
                                 ├─ 安全化したCSV
                                 └─ Web Cryptoで暗号化したバックアップ
```

- `src/ocr.ts`: 同一オリジンURL、画像上限、進捗、キャンセル、3分タイムアウト、Worker解放。先頭画像のみ処理し、次の画像は保存/スキップ後に進みます。
- `src/parser.ts`: 通貨/日付/合計/明細/カード等の候補抽出。複数合計・複数通貨・複数カード下4桁は未判定。数字のOCR置換による補完は行いません。カードのマスク記号の揺れはブランド付きの限定パターンで候補化し要確認表示。
- `src/model.ts`: データ型、許可項目の検証、カード照合、BigIntの金額演算。保存/復元の両方から呼び出します。
- `src/db.ts`: IndexedDB v2。`receipts`（idキー）、`settings`（profile・sheets・sheetVersionキー）、`sheetQueue`（レシートidキー）。v1からの更新では既存ストアを維持してキューストアだけ追加。ユーザー入力はIDBにのみ入り、public/distに入る経路はありません。
- `src/csv.ts`: CSVを出す独立したアダプター。レシートIDはUUID。
- `src/backup.ts`: v1バックアップ形式、PBKDF2/AES-GCM、サイズとスキーマ検証。
- `src/offline.ts`, `scripts/build-sw.mjs`: 全静的資産のキャッシュ、更新待機。キャッシュ名にアプリscopeとビルドハッシュを使用し、他アプリのキャッシュを削除しません。
- `scripts/prepare-assets.mjs`: 固定依存からOCRのWorker/WASM/モデルをコピー。SHA256・サイズの一覧を生成。ビルド時だけ動作し、実行時CDN取得は不要。
- `scripts/licenses.mjs`: 導入済みパッケージのライセンス一覧・通知文書を作成。

金額はDB/JSONでは小数の文字列、演算時はBigIntの最小通貨単位。SGD/USDは100分の1、JPYは1です。数量は小数3桁まで。項目が不明なら空文字を維持します。端数処理方針は店舗ごとに異なるため、数量×単価の小数端数は警告し、自動修正しません。

原本画像は選択時のみBlobとして保存し、OCR入力用Canvasは別扱いです。画像中の番号やEXIFは削除/マスキングしません。OCR全文はReactの一時状態だけに置き、保存直前には許可された項目だけを取り出します。

## 将来の直接同期

Google連携を追加する際は `src/csv.ts` と同じ出力境界に明示的な同期アダプターを置きます。Google OAuth、権限説明、利用者の同期開始操作、重複/競合解決、取消処理が別途必要です。現在のReceipt.idを同期キーに使用できます。認証トークンを固定ファイルへ埋め込んだり、バックアップへ含めたりしてはいけません。Google SDKとOAuth直接同期は未実装です。利用者の追加要望により、以下の任意のApps Script経路を実装しました。

## 任意のGoogle自動保存

`src/sheets-data.ts` が画像・OCR全文を含めない出力境界です。`src/db.ts` で確認済みレシートと送信待ちを同一トランザクションに保存し、`src/useSheetSync.ts` がオンライン時に1件ずつPOSTします。`src/SheetsSettings.tsx` が明示的な接続許可と送信先確認を担当します。Google側コードは `integrations/google-apps-script/Code.gs` です。

Sheetsの「レシート一覧」はレシートIDで更新し、「商品明細」はそのIDの行を置き換えます。更新番号と更新IDは技術用の末尾2列で、ヘッダー名を変更しないでください。受信側ロックは同時実行を直列化します。端末の時計が大きく進んでいると、それより古い端末からの更新が拒否されるため、時計を修正してから再保存します。複数端末間の双方向同期・競合マージではありません。

既存の全レシートの送信には別の明示操作が必要です。バックアップには送信キュー・キー・接続先を入れず、復元時は切断します。

## 写真日時

ReceiptにcapturedAt、importedAt、captureSourceを追加。旧バックアップでは未記録の空欄として移行します。EXIFにオフセットがあれば維持し、なければタイムゾーンを推定しません。カメラ取り込みでEXIFがなければ、アプリに戻った端末時刻を「目安」として使用。ライブラリ画像のfile.lastModifiedは撮影日時に使いません。取引日付date/time、ドラフト登録createdAtとは別です。
