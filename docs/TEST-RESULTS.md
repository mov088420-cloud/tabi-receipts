## ブラウザシナリオ

1. カード登録 → 手入力レシート → カード再判定 → 照合/保存 → 金額編集 → 集計反映 → CSVダウンロード → 暗号化バックアップ → テストデータ全削除 → バックアップ復元 → 検索。
2. 長い画像と90度回転画像の複数選択 → 1枚ずつOCR/保存 → 回転/明暗補正 → 下4桁候補 → 原本保存の再表示。
3. 店名にHTML攻撃文字列を入力/保存 → 文字列のまま表示されること → 横方向の画面あふれがないこと → デスクトップ表示。
4. 全ファイルのキャッシュ完了 → ネットワークをオフラインに設定 → 再読み込み → 実際のTesseract OCR → 店舗・合計・下4桁候補確認 → 保存 → オフライン再読み込み → データ保持。原本保存オフ時の画像不保存、OCR全文の不保存、外部通信なし、GET以外なし、ブラウザJSエラーなしを確認。
