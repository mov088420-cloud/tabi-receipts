最初は架空画像のみで実施し、その後は公開リポジトリに入れない手元の実レシートで評価します。少なくとも店舗・印字・撮影条件を分けた30枚程度について、項目別の完全一致率、手修正数、失敗率、中央値/遅い側の処理時間を記録すると採用判断に使えます。ここでの30枚は計画値で、実施済み件数ではありません。

暫定目安として、明瞭な通常画像が30秒以内、長い画像が60秒以内、処理中クラッシュなしを確認します。遅い場合は解像度上限/軽量英語モデル/ページ分割を再検討します。これらの時間は目標であり現時点のiPhone測定値ではありません。消えかけた感熱紙や強い歪みはTesseract単体の限界となる場合があります。

iPad Safari、Mac Safari、Windows Edge/Chromeでも同じ基本操作を確認してください。Google SheetsのUIとiOSダウンロード/共有動作は実環境で確認が必要です。
